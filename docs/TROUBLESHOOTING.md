# Решение проблем HA Kiosk Local

## Интеграция не подключается

Проверьте IP планшета, порт API (по умолчанию `2323`), API key и сетевой доступ Home Assistant к Android-устройству.

## `unknown command`

Android-приложение и Home Assistant integration должны быть совместимых версий. Для текущей рабочей связки используются Android **v0.3.4.1.2** и integration **v0.3.4.1.4**.

## Основная камера не открывается

В актуальной integration основная `Камера планшета` использует MJPEG relay через Home Assistant, а не прямой WebRTC/RTSP.

Проверьте:

- HA имеет LAN-доступ к IP планшета и порту `2323`;
- API key правильный;
- Android-разрешение камеры включено;
- `/api/status` планшета отвечает;
- при открытой камере `Камера передаёт видео` включается;
- `Транспорт камеры` показывает MJPEG/HA proxy режим.

Удалённому браузеру не нужен прямой доступ к планшету — он подключается только к Home Assistant.

## Камера работает только после перезапуска HA Kiosk Local

Для основной MJPEG-камеры это не должно требоваться в v0.3.4.1.4. Убедитесь, что открываете именно основную `Камера планшета`, а не дополнительную RTSP/WebRTC сущность.

Для дополнительной RTSP entity актуальная integration выполняет `camera_rtsp_stop` → `camera_rtsp_start` перед новым подключением.

## `CAMERA_IN_USE (4)`

Камера уже используется другим клиентом или фоновым monitor. Закройте сторонние приложения камеры и дайте HA Kiosk Local несколько секунд на автоматическое восстановление монитора движения/света.

## RTSP диагностика

RTSP — дополнительный режим и отключён по умолчанию. Если он включён, полезны сущности:

- `RTSP сервер камеры`;
- `RTSP подключения`;
- `RTSP порт`;
- `RTSP битрейт`;
- `Последнее RTSP подключение`;
- `Последняя ошибка камеры`.

Порт `8554` предназначен только для LAN и не должен публиковаться в Интернет.

## Нет датчика lux

Это нормально для планшетов без аппаратного light sensor. Выберите режим **Авто: lux → камера** — HA Kiosk Local будет использовать относительный уровень света камеры 0–100%.

## Экран не просыпается после темноты

Проверьте источник освещённости, порог, гистерезис, работу фонового монитора и разрешения камеры. Актуальная версия поддерживает пробуждение при устойчивом увеличении света.

## Перезагрузка планшета из HA не работает

Для системной перезагрузки HA Kiosk Local должен иметь статус Device Owner. Инструкция: [DEVICE_OWNER.md](DEVICE_OWNER.md).

## Некоторые батарейные сенсоры имеют `unknown`

Не все Android-устройства предоставляют ток, средний ток, charge counter, energy counter и thermal sensors. Это зависит от контроллера батареи и прошивки.

## После выбора HA Kiosk Local как Home неудобно открыть приложения

Удержите **Громкость −** и используйте сервисный раздел: Android Settings, смена Home/Launcher или установка APK обновления.
